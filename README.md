# Unity Game Project

A Unity and C# project containing a sample scene and scripts for basic player movement and gameplay flow.

## Project Contents

- Unity scene and project assets
- Player movement scripts
- Item collection logic
- Player life handling
- Finish trigger and end-menu scripts
- Prefabs and materials

## Built With

- Unity
- C#

## Open the Project

1. Clone or download this repository.
2. Open the project folder using Unity Hub.
3. Open the available scene from the `Assets/Scenes` directory.
4. Review the scripts under `Assets/Scripts`.

> The repository contains the Unity project source. A specific Unity Editor version and build instructions have not been documented yet.
